# スマホ側の設定（通知・アラーム・Fit／SOXAI 連携）

## 1. アプリをスマホのホーム画面に追加

1. サーバーを起動（README 参照）し、スマホのブラウザで `https://<サーバー>/` を開く
2. Android（Chrome）: メニュー →「ホーム画面に追加」／iPhone（Safari）: 共有 →「ホーム画面に追加」
3. ホーム画面のアイコンから開くと、カメラが直接起動する撮影画面になります

> プッシュ通知は **HTTPS が必須** です（PC で動かすなら `tailscale serve` などで HTTPS 化するのが簡単）。

## 2. リマインド（7:00／12:00／19:00／21:00）— 3 重に設定

| 手段 | 音 | バイブ | 特徴 |
|---|---|---|---|
| ① アプリのプッシュ通知 | ○ | ○ | タップすると撮影画面が開く。22:00 にはレポート完成の通知も届く |
| ② カレンダー（.ics） | ○ | ○ | サーバーが止まっていても鳴る |
| ③ 時計アプリのアラーム | ◎ | ◎ | マナーモード中でも確実に鳴る。止めるまで鳴り続ける |

### ① プッシュ通知
アプリ画面の「プッシュ通知をオン」→ 許可 →「テスト通知」で音とバイブを確認。
- **Android**: 設定 → アプリ → Chrome → 通知 → このサイトのカテゴリ →「音とバイブレーション」を ON、重要度「高」
- **iPhone**（iOS 16.4 以降）: ホーム画面から開いたアプリでのみ通知が使えます。設定 → 通知 → 食事記録 →「サウンド」ON

### ② カレンダー
アプリ画面の「カレンダーに追加（.ics）」をタップ → Google カレンダー／iPhone カレンダーに取り込む。
毎日繰り返しの予定 5 件（4 回の撮影リマインドと 22:00 のレポート）に、開始時刻ちょうどの通知が付きます。
Google カレンダーでは 設定 → 通知 →「通知音」「バイブレーション」を ON にしてください。

### ③ 時計アプリのアラーム（スマホ本体のアラーム）
**Android（時計アプリ）**
1. 時計 → アラーム →「＋」で 7:00 を作成
2. 「繰り返し」で全曜日を選ぶ／「ラベル」に「朝食の写真」／「バイブレーション」を ON／アラーム音を選ぶ
3. 12:00「昼食の写真」、19:00「夕食の写真」、21:00「間食・飲み物の写真」も同じように作成
4. （任意）Google アシスタントに「毎日 7 時にアラーム、ラベル 朝食の写真」と話しかけても作れます

**iPhone（時計アプリ＋ショートカット）**
1. 時計 → アラーム →「＋」→ 7:00、「繰り返し」で毎日、「ラベル」に「朝食の写真」、サウンドを選ぶ（バイブはサウンド → バイブレーションで設定）
2. 12:00／19:00／21:00 も同じように作成
3. アラームを止めた後にアプリを自動で開きたい場合: ショートカット → オートメーション →「アラーム」→「停止したとき」→ アクション「URL を開く」で `https://<サーバー>/` を指定

## 3. 消費カロリー・運動・睡眠データの連携（Fit／SOXAI RING）

### いまの状況（2026 年 11 月時点で確認）
- **Google Fit API** は Google が 2026 年中の終了を予告しています（正確な終了日は未発表）。代わりに推奨されているのは **Android のヘルスコネクト** です。
- **ヘルスコネクトのデータはスマホの中だけ** に保存され、クラウドからデータを取る API はありません。スマホ上のアプリがデータを読み出して送る必要があります。
- **SOXAI RING** の公開 API は見つかりませんでした。SOXAI アプリの設定にヘルスコネクト（または Google Fit／Apple ヘルスケア）との連携があれば、そちらに書き出すのが現実的なルートです。

### ルート A: Google Fit REST API（API が動いている間の補助手段）
1. Google Cloud Console でプロジェクトを作成し、Fitness API を有効化
2. 「OAuth クライアント ID（デスクトップアプリ）」を作成して `GOOGLE_CLIENT_ID` と `GOOGLE_CLIENT_SECRET` を設定
3. `python -m app.fit_auth` を実行し、ブラウザで許可
4. 以後、毎日 22:00 のレポート生成の直前に、総消費カロリー・歩数・体重・運動・睡眠を自動で取り込みます

### ルート B: ヘルスコネクト → HTTP 送信（Fit API 終了後もこちらで続けられる）
SOXAI アプリ → ヘルスコネクト（Fit も同期 ON）→ ヘルスコネクトを読み出せる自動化アプリ → `POST /api/health`

送る JSON（1 日分。複数日を配列で送っても可）:
```json
{"date":"2026-11-23","source":"soxai","total_burn_kcal":2450,"active_kcal":520,
 "steps":9200,"sleep_min":410,"weight_kg":72.4,
 "workouts":[{"type":"EXERCISE_TYPE_STRENGTH_TRAINING","minutes":60,"kcal":280}]}
```
- `INGEST_TOKEN` を設定した場合は、ヘッダーに `Authorization: Bearer <トークン>` を付けます
- ヘルスコネクトの運動種別名（`EXERCISE_TYPE_...`）はそのまま送れば自動で変換されます

### ルート C: CSV 取り込み
`POST /api/health/csv` に CSV をアップロードします。
- 日別データの列: `date,total_burn_kcal,active_kcal,steps,sleep_min,weight_kg`
- 運動データの列: `date,type,name,minutes,kcal,sets,muscle_groups`（部位は `;` 区切りで `chest;arms`）

### ルート D: 手入力（いちばん確実）
アプリ画面の「今日の消費・体のデータ」に、SOXAI アプリや Fit に表示されている総消費カロリー・歩数・睡眠・体重を入れます（1 日 30 秒程度）。

### 筋トレの部位・セット数
リングや Fit では「どの部位を何セット」は分からないため、アプリ画面の「筋トレを記録」で補ってください。週 2 回以上・週 10 セット以上の判定に使います。
